\# Documentation (docs)



This folder stores supporting documentation and materials related to the Travel Budget Management Chatbot project.



\## 1. Purpose



The purpose of this folder is to organise additional project documents that support the system's development, implementation and presentation.



\## 2. Possible Contents



The folder may contain:



\- System architecture diagrams.

\- Project presentation slides.

\- Meeting notes and progress records.

\- Screenshots of the chatbot application.

\- Other supporting project documents.



\## 3. File Organisation



Keep supporting documents in this folder and use clear, descriptive file names to make them easier to identify and maintain.
